DON'T WAKE THE PUMPKIN KING: MAP PROP PROMPTS

Where: Roblox Studio Assistant (Cube 3D), Meshy or Tripo.
How: paste one prompt at a time. Rename each model to the MODEL NAME shown (exact spelling, no spaces). Put them all in a folder called MapModels, right-click > Save to File > mapmodels.rbxm, and hand the file to your agent. Each one replaces the matching block prop on the map; anything missing keeps the current look.
Style line already included in every prompt, so they all match.
Tips: props are scenery, so keep each under ~3,000 triangles (big ones like the mausoleum or throne under ~6,000). No glow is baked in; the game adds lights. Make them a bit chunky, because they get scaled up and down on the map.
