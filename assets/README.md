# assets/

Reusable assets, examples and small generators the workflow uses. Everything here was made for the reference game
(*Don't Wake the Pumpkin King*) by its owner and his AI agents: original art, original sounds, our own scripts.
No third-party audio, images or place files. Binaries are kept few and small (all < 100 KB).

**License:** scripts and text files are MIT (repo `LICENSE`). Images and sounds are the repo owner's own work, also
released under MIT so you can study and remix them; please don't present the Pumpkin King character or branding as
your own game's art. Swap in your own art for a real game.

## How the pieces fit the workflow
- Icon/thumbnail loop: generate masters -> `make_sizes.py` -> `feed_sheet.py` + personas -> upload 3-5 -> personalization
  test for 7 days (docs/marketing-launch.md).
- Models: prompt pack -> owner generates and saves one `.rbxm` -> build swaps by name (docs/models-and-audio.md).
- Sounds: make original SFX -> Open Cloud upload -> bake the ID with `Sound.AudioContent` (Lune 0.10) (docs/models-and-audio.md).
- Balance: `rebirth_curve.py` picture + table -> owner decides -> numbers go into Config attributes.

Roblox asset IDs above belong to the reference game's owner; they're listed as examples of where the files ended up and
won't be usable in your own place unless the asset is shared with you. Upload your own copies.
